# SJCC Library Website

A responsive static website for the San Jose Community College Library Department.

## Included
- Home
- About
- Services
- Resources
- Searchable catalog interface
- Guidelines
- Announcements
- Contact page
- Mobile navigation
- Sample catalog data
- No server/database required for the initial version

## How to use
1. Open `index.html` in a browser to preview the site.
2. Replace sample catalog records in `assets/script.js` or connect the catalog interface to your real database/API.
3. Update official SJCC contact details, social links, logo, policies, and announcements before public deployment.
4. Upload the entire folder to a static host such as GitHub Pages, Netlify, Vercel, or your institution's web server.

## Important
This is a first deployable static version. The catalog is currently a browser-side sample search and does NOT save or modify records. A real catalog/admin system requires a backend/database and authentication.

## Branding
The current design uses an institutional blue/violet palette and a text-based SJCC mark. Replace `assets/favicon.svg` and the brand mark with the official approved SJCC logo if available.
